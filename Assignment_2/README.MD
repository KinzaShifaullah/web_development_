## About the Project

VELORA is a fictional luxury perfume e-commerce website. It is designed to provide a simple and elegant shopping experience for customers looking for different fragrances.

The website design is inspired by J. Junaid Jamshed's fragrance collection, but uses its own brand name, product images and layout.

## Technologies Used

- HTML5
- Tailwind CSS
- Custom CSS

## Website Pages

- **index.html:** Homepage with navigation, hero banner, perfume collections and product cards.
- **product.html:** Product detail page with image, price, description, quantity selector and Add to Cart button.
- **style.css:** Custom styling and responsive design.
